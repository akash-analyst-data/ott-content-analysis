
# OTT Content Analysis

## Objective
Analyze OTT platform data to understand content trends and user preferences.

## Tools Used
Python (Pandas, NumPy), Matplotlib, Seaborn

## Analysis Performed
- Genre distribution
- Content trends over time
- Rating analysis

## Insights
- Identified popular genres and content patterns
- Observed trends in content release

## Business Impact
Helps optimize content strategy and audience targeting.
